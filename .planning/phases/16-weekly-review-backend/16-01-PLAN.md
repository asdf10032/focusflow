# Plan 16-01: Weekly Review API and Aggregation

## Objective

Add a deterministic weekly review endpoint that aggregates execution-history snapshots for one Monday-Sunday week and compares it with the previous week when data exists.

## Tasks

<task id="16-01-01">
Add weekly review schemas.

- Add weekly summary, day, comparison delta, comparison, and response schemas to the existing execution schema module.
- Reuse the existing daily review item schema for day-level log items.
- Keep existing daily review schemas unchanged.
</task>

<task id="16-01-02">
Add weekly aggregation helpers.

- Resolve any requested date to Monday `week_start` and Sunday `week_end`.
- Query execution logs by inclusive date range, ordered by date, `created_at`, and `id`.
- Calculate `logged_count`, `completed_count`, `skipped_incomplete_count`, `completion_rate`, `planned_minutes`, `actual_minutes`, and `estimate_variance_minutes`.
- Treat null `actual_minutes` as absent from actual totals.
- Return `estimate_variance_minutes: null` for periods with no logs.
</task>

<task id="16-01-03">
Add previous-week comparison.

- Compare the selected week with the immediately previous Monday-Sunday week.
- When previous-week logs exist, return previous summary and deltas for completion rate, actual minutes, and estimate variance.
- When previous-week logs do not exist, return `available: false`, `previous_summary: null`, `deltas: null`, and `message_code: "previous_week_unavailable"`.
</task>

<task id="16-01-04">
Add the weekly review route.

- Add `GET /api/v1/execution/weekly-review?date=YYYY-MM-DD`.
- Return the existing success envelope.
- Use only execution logs; do not require selected schedule plans.
- Do not mutate tasks, schedules, or logs.
</task>

<task id="16-01-05">
Add focused tests.

- Cover week boundaries, aggregation, day breakdown, snapshot preservation, comparison deltas, empty comparison metadata, empty week behavior, and success envelope behavior.
- Keep daily review tests passing.
</task>
