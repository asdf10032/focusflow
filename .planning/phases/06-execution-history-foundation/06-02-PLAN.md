# 06-02 Plan: Feedback History APIs and Tests

## Goal

Update execution feedback to create history records while preserving v1.0 response compatibility.

## Scope

- Extend `POST /api/v1/execution/feedback` with optional `date`, `actual_minutes`, and `note`.
- Keep response data as updated `TaskOut`.
- Add `GET /api/v1/execution/history?date=YYYY-MM-DD`.
- Normalize feedback history statuses and map them to existing task statuses.
- Add backend tests for history creation, date filtering, status mapping, missing tasks, and snapshots.
