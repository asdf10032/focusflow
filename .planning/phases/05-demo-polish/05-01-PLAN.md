# Phase 5 Plan 05-01: Demo Data and Smoke Test

## Goal

Make the project seedable into a deterministic local demo state and verify the end-to-end demo loop with one focused smoke test.

## Scope

- Add `backend/app/services/seeds/demo_data.py`.
- Expose `seed_demo_data(db, target_date=None)` for tests and future tooling.
- Add CLI usage through `python -m backend.app.services.seeds.demo_data` with optional `--date YYYY-MM-DD`.
- Seed default energy templates, one demo project, five realistic tasks, one blocked time, three schedule plans, and select the balanced plan.
- Extract schedule plan persistence into a reusable service so API generation/reoptimization and demo seeding share behavior.
- Add `tests/test_demo_flow.py` for the full local demo flow.

## Out Of Scope

- No database migration.
- No destructive reset behavior.
- No new product UI feature.
- No external AI or network dependency.

## Acceptance

- Demo seeding is idempotent for the target date.
- Existing schedule API response shapes are unchanged.
- The smoke test confirms success envelopes for execution and parse-task endpoints.
