# Plan 11-01: Frontend Suggestion API and Presentation Helpers

## Objective

Add the typed frontend foundation needed for the Tasks page to call Phase 10 duration suggestions and display localized suggestion metadata.

## Context

- Phase 10 added `POST /api/v1/ai/suggest-duration`.
- `frontend/src/lib/api.ts` already owns typed API client methods.
- `frontend/src/lib/i18n.ts` owns all bilingual UI copy and status labels.
- Existing frontend tests exercise i18n completeness and helper stability through small Node transpilation scripts.

## Tasks

<task id="11-01-01">
Add API types and client method.

- Add `DurationSuggestionRequest` type with `title`, optional `project_id`, optional `cognitive_load`, and optional `estimated_minutes`.
- Add `DurationSuggestion` type with `suggested_minutes`, `confidence`, `sample_count`, `source`, `reason_code`, and `reason`.
- Add `suggestTaskDuration(payload)` that posts to `/ai/suggest-duration`.
- Keep `parseTaskDraft` response shape unchanged in this plan.
</task>

<task id="11-01-02">
Add localized suggestion copy.

- Extend `TranslationKey` with task suggestion labels, actions, states, and reason-code labels.
- Add matching keys in both `zh-CN` and `en`.
- Include copy for:
  - section title;
  - request button;
  - accept button;
  - suggested minutes;
  - confidence;
  - sample count;
  - history/fallback source;
  - suggestion load failure;
  - accepted confirmation;
  - no-suggestion/needs-title state.
- Add localized reason-code labels for Phase 10 reason codes:
  - `history_project_load_match`
  - `history_project_match`
  - `history_load_match`
  - `history_title_match`
  - `fallback_current_estimate`
  - `fallback_low_load`
  - `fallback_medium_load`
  - `fallback_high_load`
</task>

<task id="11-01-03">
Add small helper coverage where useful.

- If reason-code display is implemented as a helper, add a frontend helper test for known and unknown reason codes.
- Extend `tests/test_frontend_i18n.py` with a Phase 11 key list.
- Keep tests independent of browser automation.
</task>

## Must Haves

- Frontend API method exactly matches Phase 10 wire shape.
- Translation keys are complete for both supported languages.
- No Tasks page behavior changes are required in this plan.
