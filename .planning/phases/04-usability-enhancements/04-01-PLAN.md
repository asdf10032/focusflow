# 04-01 Plan: Backend Usability APIs

## Goal

Add backend endpoints for schedule validation, reoptimization, today execution, feedback, and local task parsing without adding migrations.

## Changes

- Extend schedule schemas and endpoints with `POST /schedules/validate-move` and `POST /schedules/reoptimize`.
- Add execution endpoints:
  - `GET /execution/today?date=YYYY-MM-DD`
  - `POST /execution/feedback`
- Add local deterministic parse endpoint:
  - `POST /ai/parse-task`
- Keep all responses inside the existing success/error envelope.

## Tests

- Add Phase 4 API tests for valid moves, overlap/missing-plan conflicts, reoptimization, today execution, feedback, and parse-task drafts.
