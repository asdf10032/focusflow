# Plan 15-02: Search UI and Empty States

## Objective

Expose task search and polish empty/export states across the v1.3 user path with Chinese and English copy.

## Context

- Tasks already has status/project filters and export controls.
- Calendar, Today, and Daily Review already render basic empty states.
- Phase 13 added export controls; Phase 14 added partial replan errors.
- Phase 15 should polish existing surfaces without adding new navigation or broad redesign.

## Tasks

<task id="15-02-01">
Add task notes and search controls to Tasks.

- Add a notes textarea to task create/edit form.
- Preserve notes when editing an existing task.
- Add a search input in the existing filters panel.
- Filter visible tasks by title/notes search, status, and project using the helper from `taskView.ts`.
- Show search-specific empty copy when tasks exist but filters/search return no matches.
</task>

<task id="15-02-02">
Improve task export empty handling.

- When task export returns `record_count === 0`, show localized `exports.empty` and do not trigger an empty download.
- Keep export success/failure behavior unchanged for non-empty exports.
</task>

<task id="15-02-03">
Polish Calendar empty states.

- Keep the existing no-plan state, but make copy distinguish:
  - no generated plans yet;
  - generated plan has no items;
  - partial replan cannot proceed because no selected plan, no remaining work, or no schedulable time.
- Do not add side-by-side partial replan comparison.
</task>

<task id="15-02-04">
Polish Today and Daily Review empty/export states.

- Today should clearly distinguish no selected plan from a selected plan with no remaining items.
- Daily Review should show localized empty history copy and avoid downloading empty history/review exports when `record_count === 0`.
- Keep existing progress/review metric layouts.
</task>

<task id="15-02-05">
Extend i18n and frontend tests.

- Add Chinese and English keys for:
  - task notes label/placeholder;
  - task search label/placeholder;
  - no search results;
  - export empty/no-download feedback;
  - improved Calendar/Today/Review empty states as needed.
- Extend `tests/test_frontend_i18n.py` for all new keys.
- Extend `tests/test_frontend_view_helpers.py` for search/filter composition.
</task>

## Must Haves

- Search, filters, and empty states work without network calls beyond existing task loading.
- Text stays concise and localized.
- Existing Tasks, Calendar, Today, Daily Review, and export flows remain intact.
- No Phase 15 UI changes add cloud sync, import, weekly planning, or comparison views.

python -m pytest tests/test_phase15_task_search.py tests/test_frontend_i18n.py tests/test_frontend_view_helpers.py -q -p no:cacheprovider
