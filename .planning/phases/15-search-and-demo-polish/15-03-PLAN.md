# Plan 15-03: v1.3 Demo Polish and Milestone Readiness

## Objective

Make v1.3 demonstrable end-to-end and leave the milestone ready for verification/archival.

## Context

- Demo seeding is repeatable and non-destructive.
- Phase 13 added export APIs/UI.
- Phase 14 added selected-plan-based partial replan.
- Phase 15 must prove the complete v1.3 loop without requiring network access.

## Tasks

<task id="15-03-01">
Update demo seed for v1.3.

- Ensure seeded tasks include notes that can be searched from Tasks.
- Ensure seeded data has:
  - at least one selected balanced plan;
  - execution logs for the selected date;
  - enough remaining selected work for partial replan after feedbacked work is excluded;
  - exportable task/history/review data.
- Keep seed behavior repeatable and non-destructive.
</task>

<task id="15-03-02">
Extend smoke coverage.

- Extend `tests/test_demo_flow.py` to verify:
  - seed data includes searchable notes;
  - task export returns non-empty payload;
  - execution history export returns non-empty payload;
  - partial replan excludes feedbacked work and returns selectable plans;
  - selecting a replanned plan succeeds;
  - Today and Daily Review continue returning success envelopes after the replan loop.
- Keep existing v1.0-v1.2 smoke assertions intact.
</task>

  - frontend install/dev/build commands;
  - verification commands;
  - exact demo path: Tasks search -> Exports -> Calendar partial replan -> Select Plan -> Today feedback -> Daily Review.

</task>
